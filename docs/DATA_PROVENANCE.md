# Data provenance

All datasets used in this study are public aggregate statistics. No individual-level data were accessed.

## 1. FinnGen R11 genome-wide summary statistics (genetic layer)

- Source: FinnGen public release R11, Google Cloud Storage bucket.
- URL template: `https://storage.googleapis.com/finngen-public-data-r11/summary_stats/finngen_R11_<ENDPOINT>.gz`
- Download date: 2026-10-31. `scripts/01_download.py` reproduces the download with resume support and verifies the byte size of every file.
- Raw files are not shipped (~815 MB each, ~9 GB total) and were not retained locally after munging. The munged per-trait files that fed LD score regression are likewise not shipped (~123 MB each), but their sha256 and byte sizes are recorded in `results/metadata/input_manifest.json`, which also records the sha256 of every shipped qc/rg output; anyone re-running stages 01-02 can verify byte-identity against that manifest. (`environment_check.json` shows `raw_ready: 0` because the raw downloads were cleaned up after munging; this is expected.)

## 2. LD scores and reference SNP list (genetic layer)

- 22 autosome LD-score files plus a reference SNP list (9,997,231 SNPs), computed with the reference `ldsc.py` implementation (`--l2 --ld-wind-kb 1000`) from the 1000 Genomes European quality-controlled reference panel, as stated in the manuscript Methods.
- Not shipped (126 MB compressed). To rebuild: download the 1000 Genomes European reference panel (PLINK format), then run `ldsc.py --bfile <panel> --l2 --ld-wind-kb 1000` per autosome and extract the reference rsID list; or contact the authors for the exact files used here.
- Munged per-trait files (`derived/<trait>.sumstats.tsv.gz`, ~123 MB each, 1.3 GB total) are likewise not shipped; they are regenerated by stages 01-02.

## 3. Disease-trajectory aggregate export (trajectory layer)

- Source: Danish Disease Trajectory Browser (DTB) aggregate export, as published in Siggaard et al., Nature Communications 2020.
- The exact export file analysed in this study is shipped at `data/dtb_supp1.tsv` (77,294 directed disease-pair records; sha256 in `results/metadata/input_manifest.json`). Reviewers can also query the same records interactively in the DTB web tool (diagnosis-pair query on ICD-10 H35), but no separate export script is provided; the file here is the authoritative input.
- `analysis/build_traj_tables.py` regenerates `results/traj_all_pairs.tsv` (all 421 directed H35 records) and `results/traj_main_table.tsv` from that export; output is byte-identical to the shipped tables. Diagnosis names are WHO ICD-10 three-character titles (`analysis/icd10_dict.py`).
- Underlying registry: Danish National Patient Registry, 1994-01 to 2018-04, 7,186,865 patients, 122 million hospital contacts; ICD-10 three-character codes linked with the death registry.
- Individual-level data require approval from the Danish Data Protection Agency and the Danish Health Authority; this study used only the published aggregate statistics.
- Note on directionality P values: 26 records (all with RR < 1; 22 of them sex-specific codes, 4 not) carry published directionality P values below the exact-binomial floor for their sample size, indicating distributional approximation in the original resource. These records are flagged in Supplementary Table S1 and no conclusion relies on their exact tail probabilities.
