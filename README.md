# AMD-trajectory-LDSC-Reproducibility

Reproducibility package for the manuscript "Narrow systemic footprint of macular degeneration: a disease-trajectory and cross-trait genetic correlation study".

This repository contains every script and every derived result needed to regenerate all tables, figures, and in-text numbers of both layers. The trajectory layer is fully reproducible from the shipped DTB aggregate export (`data/dtb_supp1.tsv` + `analysis/build_traj_tables.py`). Multi-GB source files (FinnGen R11 raw summary statistics, LD-score files) are not shipped; `docs/DATA_PROVENANCE.md` documents exactly how to re-obtain or rebuild them, and `results/metadata/input_manifest.json` binds every shipped result to sha256 hashes of the exact pipeline inputs used.

## Contents

```
config/endpoints.tsv          FinnGen R11 endpoints: trait code, endpoint name, n_cases, n_controls, expected file size
data/dtb_supp1.tsv            Danish Disease Trajectory Browser aggregate export (77,294 records; source of the trajectory layer)
scripts/00_check_environment.py   environment sanity check
scripts/01_download.py        resumable download of the 11 FinnGen R11 summary-statistics files
scripts/02_munge.py           rsID-restricted munging to a common SNP set (tolerates malformed source rows)
scripts/03_rg.py              cross-trait LD score regression (validated estimator, see Methods)
scripts/common.py             shared path/config helpers
analysis/build_traj_tables.py rebuilds both trajectory tables from data/dtb_supp1.tsv
analysis/icd10_dict.py        WHO ICD-10 three-character code-to-name dictionary
analysis/emit_numbers.py      assembles ms_numbers.json from results/ (fails loudly on any missing value)
analysis/fig1.py              Figure 1 (trajectory bubble plot)
analysis/fig2.py              Figure 2 (genetic-correlation forest plot)
analysis/make_supp.py         Supplementary Tables S1-S4 (xlsx)
results/                      all pipeline outputs (see below)
docs/DATA_PROVENANCE.md       source datasets, versions, download dates, rebuild instructions
MANIFEST.csv                  path, size, sha256 for every file except itself
SHA256SUMS.txt                sha256 sums (coreutils format)
Verify_Archive_Integrity.py   integrity + completeness check (run after extraction)
```

## results/

- `qc_<trait>.json` (11 files): per-trait LDSC QC on the primary analysis frame (nsnp, mean chi2, lambda GC, observed-scale h2, intercept).
- `rg_<pair>.json` (9 files): genetic correlation for each pair under three variant sets: V1 (MAF >= 0.05, primary), V2 (MAF >= 0.01), V3 (V1 minus the MHC region, chr6:25-34 Mb). Each entry: rg, se, z, p, h2a/h2b with jackknife SEs, intercepts, nsnp.
- `traj_main_table.tsv`, `traj_all_pairs.tsv`: trajectory-layer aggregate tables (main 17 RR>1 records; all 421 ordered records with directionality statistics).
- `ms_numbers.json`: every numeric value cited in the manuscript, assembled by `analysis/emit_numbers.py`.
- `fig1_trajectories.png/.pdf`, `fig2_rg_forest.png/.pdf`, `supplement_S1_S4.xlsx`: reference outputs regenerated by the analysis scripts.
- `metadata/environment_check.json`: package versions of the production environment (`raw_ready: 0` there records that raw FinnGen downloads were deleted after munging, not a pipeline failure).
- `metadata/input_manifest.json`: sha256 + byte size of every pipeline input (11 munged sumstats, LD scores, reference SNP list, DTB export) and of every qc/rg output, binding results to the exact files they were computed from.

## Quick start (figures and tables only, using shipped results)

```bash
pip install -r requirements.txt
python3 analysis/build_traj_tables.py  # rebuilds both trajectory tables from the shipped DTB export
python3 analysis/emit_numbers.py   # regenerates results/ms_numbers.json
python3 analysis/fig1.py           # regenerates results/fig1_trajectories.png/.pdf
python3 analysis/fig2.py           # regenerates results/fig2_rg_forest.png/.pdf
python3 analysis/make_supp.py      # regenerates results/supplement_S1_S4.xlsx
```

## Full pipeline from raw data

```bash
python3 scripts/00_check_environment.py
python3 scripts/01_download.py     # downloads ~9 GB from FinnGen R11 public storage (resumable)
python3 scripts/02_munge.py        # restricts to the 9,997,231-SNP reference set (see docs/DATA_PROVENANCE.md)
python3 scripts/03_rg.py main      # per-trait QC + V1/V3 for all 9 pairs
python3 scripts/03_rg.py v2        # V2 for all 9 pairs
```

Stage 02 additionally requires the LD-score SNP list and stage 03 the 22 autosome LD-score files; both are documented in `docs/DATA_PROVENANCE.md`. Stages 01-02 shell out to bash, awk and gzip, so the full pipeline is POSIX-only; the analysis scripts run on any platform.

## Integrity

After downloading or cloning, run:

```bash
python3 Verify_Archive_Integrity.py
```

which checks every file against `SHA256SUMS.txt`, fails on any unlisted file in the tree, and confirms the required tree is complete.
